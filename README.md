# جولتي · Jawlati

تطبيق Flutter عربي للعمليات الميدانية لمندوبي المبيعات. يضم شاشات العملاء والزيارات والفواتير والقبض والطلبات والجرد.

## التشغيل المحلي

استخدم Flutter 3.44.8، كما هو محدد في `.fvmrc`، ومحاكي Android أو iOS. الحد الأدنى المستهدف لأجهزة iPhone هو iOS 15. إذا كنت تستخدم FVM، شغّل `fvm install` ثم استخدم `fvm flutter` في الأوامر التالية.

```sh
flutter --version
flutter pub get
flutter devices
flutter run -d <device-id>
```

افتح **دخول النسخة التجريبية** للوصول إلى الواجهة الرئيسية. التشغيل الافتراضي محلي، والواجهة الرئيسية تعتمد على بيانات العرض الموجودة في التطبيق. بدء زيارة فعلية يستخدم خدمة الموقع وصلاحية الجهاز.

## التحقق

```sh
flutter analyze --no-pub
flutter test --no-pub
```

يغطي اختبار الواجهة فتح شاشة «جولتي» والتنقل إلى لوحة المندوب. توجد ملاحظات تحليل موروثة، ويشمل نطاق الميزات اللاحق استقرار الحفظ ومعالجة حالات الفشل.

## حدود النسخة

- الدخول التجريبي يفتح لوحة المندوب مباشرة. المصادقة الفعلية خارج نطاق هذه النسخة.
- لا يوجد عنوان API افتراضي. يمكن ضبط عنوان بيئة تطوير عند العمل على التكامل باستخدام `--dart-define=JAWLATI_API_BASE_URL=...`.
- تخزين الزيارات محلي. حفظ الفواتير وإرسال الجرد ما زالا تجريبيين.
- الهوية البصرية مؤقتة، ومعرّف التطبيق على Android وiOS هو `com.ibrahimdeeb.jawlati`.
- تأسست نسخة Flutter من commit `f71a099` في `ok-tech-app`.
